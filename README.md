# دعوة زفاف Aml & Esam

موقع ثابت (HTML + CSS + JS) بدون أي خدمات مدفوعة.

## الملفات
- `index.html` — الصفحة
- `style.css` — التصميم (خطوط Cairo للعربي و Montserrat للإنجليزي)
- `script.js` — الظرف، العداد التنازلي، زر الموسيقى
- `audio/wedding-song.mp3` — الأغنية (نفس الملف المرفق، بدون أي تعديل)

## الموسيقى
- الأغنية بتشتغل **أول ما الزائر يضغط على الظرف** (المتصفحات بتمنع التشغيل قبل أي ضغطة)، وزر "تشغيل الموسيقى" بيوقفها ويشغلها تاني.
- المسار نسبي (`audio/wedding-song.mp3`) فبيشتغل على Vercel زي ما بيشتغل محليًا.

## تغيير الموعد أو الرابط لاحقًا
- الموعد: `script.js` → `new Date('2026-12-11T20:00:00+02:00')`
- رابط الخريطة: `index.html` → زر OPEN LOCATION

## رفع النسخة الجديدة على Vercel

### لو المشروع القديم على GitHub
1. استبدل ملفات المشروع القديم بمحتوى هذا المجلد (بما فيها مجلد `audio`).
2. اعمل Commit و Push.
3. Vercel هينشر تلقائيًا، وبعد دقيقة الرابط القديم هيتحدث.

### لو مفيش GitHub (Vercel CLI)
```
npm i -g vercel
cd aml-esam-wedding
vercel --prod
```
أول مرة هيسألك تسجل دخول، ولو عايز يحدّث نفس المشروع القديم اختار نفس اسم المشروع.

### إعدادات Vercel
- Framework Preset: Other
- Build Command و Output Directory: سيبهم فاضيين

### بعد النشر
افتح الرابط من الموبايل وجرب: فتح الظرف، زر الموسيقى، العداد، زر الموقع.
لو الأغنية القديمة لسه ظاهرة، اعمل Refresh قوي أو افتح الرابط في نافذة خاصة.
